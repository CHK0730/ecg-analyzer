## 📁 支援格式

| 格式 | 說明 |
|------|------|
| `.abf` | Axon Binary Format（pyabf；另含內建 ABF v1 備援解析器，pyabf 不支援的浮點資料檔也能開） |
| `.edf` | European Data Format（內建解析器） |
| `.acq` | **BIOPAC AcqKnowledge 原生格式**（需 bioread）。會一併讀出錄製時按下的事件標記 |

**建議優先用 `.acq` 而不是轉出來的 `.edf`**：EDF 的通道名稱上限只有 16 字元會被截斷，且轉檔時常會產生降頻的重複通道、標籤也可能對不上；**轉成 EDF 也會把錄製時按下的事件標記整個丟掉**。直接讀 `.acq` 可以避免這些問題。

三種格式都支援**各通道不同取樣率**（例如 BIOPAC 的 frequency divider：部分通道 10 kHz、部分 5 kHz）。每個通道都用自己的取樣率換算時間軸。

## 🗂️ 兩個頁面

**右側欄位最上方**可切換 **ECG** 與 **SKNA** 兩頁，選中的那頁以實心底色標示。兩頁共用同一個波形區，**切換頁面不會改變目前檢視的位置**。

| | ECG 頁 | SKNA 頁 |
|---|---|---|
| **工具列（專屬）** | 偵測 R-peaks、編輯 R-peak、清除 R-peak、濾波、匯入實驗記錄 | 疊心電成分、SKNA 區間分析 |
| **側邊欄（專屬）** | 時間測量、節律分析、時間戳記 | SKNA 設定（含 S3 分解）、SKNA 時間點位、SKNA 時間區段 |

**兩頁共用**：開啟、◀ 往前、往後 ▶、放大、縮小、重設、測量／新增點位、截圖、前往時間點、說明；側邊欄的檔案資訊與目前視窗。

進入 SKNA 頁會**自動開啟 SKNA 顯示**，離開時自動關閉，不必再按開關。SKNA 設定與 S3 分解都在右側欄位裡。

SKNA 模式下軌道 2 畫的是分析結果，所以它的**通道選單會鎖住**（標題變成「軌道 2（SKNA）」並指向 SKNA 來源通道，要改請到「SKNA 設定」）；**▲ ▼ 自動 縱軸按鈕不受影響，照常可用**。回到 ECG 頁，選單會解鎖並回到你原本選的通道。

**縱軸控制**（▲ ▼ 自動）在**各軌道標題列的通道選單旁邊**。快捷鍵不變：軌道 1 用 W / S，軌道 2 用 E / C。

### 「測量」按鈕在兩頁行為不同

| 頁面 | 行為 |
|---|---|
| ECG | **測量** — 點 A 點、再點 B 點，側邊欄顯示 Δt 與該範圍平均 BPM |
| SKNA | **新增點位** — 點擊波形後輸入名稱，並選擇「起點」或「終點」 |

### SKNA 頁側邊欄

- **SKNA 設定** — 演算法、來源通道、ECG 參考通道、帶通、包絡窗長、S3 狀態（未使用／尚未分解 ⚠／已分解），以及「SKNA 設定...」「S3 分解（整檔）」兩顆按鈕
- **SKNA 時間點位** — 標記清單。起點顯示綠色、終點紅色，沒配到對的標黃字「尚未配對」。雙擊跳到該點位
- **SKNA 時間區段** — 由點位自動配對出來的分析區間（前面有 📍），加上手動加入的區間。每筆顯示起訖、長度與 aSKNA

### 自動帶入 .acq 的事件標記

開啟 `.acq` 時，程式會把你在 AcqKnowledge 錄製過程中按下的**使用者標記**直接讀進來，依時間排序後第 1↔2、3↔4… 成對，變成 SKNA 時間點位與分析區間。這些點位在側邊欄會標上 📍檔案，和自己在畫面上點的分開。

名稱取自起點標記的文字；如果錄製時只在起點打了字（常見作法），終點會沿用同一個名稱；兩端都留空就自動命名為「區段 1／2／3」。狀態列會顯示帶入了幾個點位。

AcqKnowledge 另外會寫入 `分段 N …` 這種**分段接續標記**，那是儀器記錄「這裡接上了一段新錄製」的位置，不是實驗事件，因此不會帶入。

帶入只做一次，之後就以 `檔名_SKNA_marks.json` 為準：**刪掉或搬動了哪些點位，下次開檔不會又長回來**。既有的手動點位也不會被覆蓋——時間相差 0.2 秒以內的視為同一個點，不重複加入。

實測 7 個檔案（`AMI 02` 與 `HFD2-1/3/4/5/6/9`）都乾淨地得到 3 個區間，例如 `AMI 02`：

| 區間 | 起訖 | 長度 |
|---|---|---|
| baseline | 00:48.1 → 05:54.0 | 305.8 s |
| stress | 06:08.5 → 09:16.6 | 188.1 s |
| recovery | 09:23.7 → 12:30.8 | 187.1 s |

`.abf` 與 `.edf` 沒有這類標記，仍需手動標。

### 時間點位怎麼用

1. 切到 SKNA 頁，按工具列「新增點位」（或 **M**，或側邊欄「＋ 新增時間點位」）
2. 在波形上點一下想標記的時間 → 輸入名稱，選「起點」或「終點」
3. 重複標出想分析的區段

每個**起點**會和它之後**最近的一個終點**自動配對成一段分析區間，SKNA 指標立刻算好，並同時出現在側邊欄的「SKNA 時間區段」、「SKNA 區間分析」視窗與 Excel 匯出裡。改動 SKNA 設定或跑完 S3 之後，所有區間會自動重算。

對話框會依前一個點位自動建議類型與名稱（標了起點就建議終點、名稱沿用），連續標記時不必重打。

點位存在 `檔名_SKNA_marks.json`，下次開同一個檔案會自動載回（含「是否已從 .acq 帶入過」的記錄）。

「SKNA 時間區段」清單與「SKNA 區間分析」視窗是**同一份資料**，任一邊新增或刪除，另一邊立刻同步。

## 🧠 SKNA 分析

皮膚交感神經活性（Skin Sympathetic Nerve Activity）分析，實作文獻中的傳統帶通濾波法（rSNA-BPF），並提供 S3 分解以移除心電干擾。

### 處理流程

```
原始訊號 → Butterworth 帶通（預設 500–1500 Hz，4 階 SOS，零相位）
        → rSNA
        → 全波整流 |rSNA|
        → 移動平均（預設 100 ms）→ 整流包絡 iSKNA
        → 區間統計（使用區間內全部樣本）
```

### 使用 S3 的三個步驟

S3 需要先對整個檔案跑一次分解，**不是選了就生效**：

1. 「SKNA 設定」→ 演算法選 **S3** → 按「套用」
2. 跳出詢問時選「是」執行分解（或按右側欄位的「S3 分解（整檔）」）
3. 分解完成後畫面會**自動切換**到 SKNA 顯示，軌道 2 標籤變成 `SKNA [S3] ...`

判斷目前狀態：看軌道 2 的標籤。`[S3]` = 正在用 S3；`[BPF]` = 傳統帶通；若出現「⚠ 尚未執行 S3 分解」就是還沒跑。工具列右側也會顯示 `S3 ✓` 或 `S3（待分解）`。

程式提供兩種演算法，可在「SKNA 設定」裡切換：

| 演算法 | 怎麼分離心跳 | 適用 |
|---|---|---|
| **BPF** | 只在**頻率**上切；統計時使用區間內全部樣本，不排除任何資料 | 快、不需前置運算，與文獻傳統作法一致 |
| **S3** | 在**波形形態**上切：分解掉整個心電成分 | 效果好，尤其是低頻帶；需先跑一次分解 |

### 工具列

- **SKNA (K)** — 軌道 2 切換成 SKNA 顯示：rSNA 細線 + 橘色整流包絡，軸標籤即時顯示目前視窗的 aSKNA 與目前使用的演算法
- **SKNA 設定...** — 演算法、來源通道、ECG 參考通道、頻帶、濾波器階數、包絡窗長、R-peak 來源
- **S3 分解** — 對整個檔案執行 S3（12 分鐘的檔約 15 秒）
- **疊心電成分** — 在軌道 1 疊上 S3 分離出來的心電成分（紅色），用來確認分解是否貼合實際 QRS
- **SKNA 區間分析...** — 建立時間區間、計算指標、匯出 Excel

### 頻帶預設值

| 預設 | 適用情境 |
|------|----------|
| 500–1500 Hz | 高採樣率錄製（≥ 3 kHz），本程式預設 |
| 500–1000 Hz | 文獻傳統值 |
| 300–500 Hz | Holter 等 1 kHz 採樣的設備 |

高截止若超過該通道的 Nyquist（fs / 2）會自動夾住並在介面上標示 ⚠。

### ⚠️ BPF 模式的心跳殘留

BPF 模式**不做任何樣本排除**：aSKNA／iSKNA 一律用區間內全部樣本計算（含 QRS），與文獻傳統作法一致。

要知道的限制是：心跳是準週期的尖峰訊號，QRS 的高階諧波會延伸到很高的頻率，**洩漏進 SKNA 的通帶裡**，心率越高越嚴重：

- 人類（HR 60–80）影響有限
- **小鼠（HR 約 400 bpm）**：實測在 500–1500 Hz 帶內，QRS 窗內的振幅是窗外的 **3–5 倍**

也就是說，BPF 的 aSKNA 裡會含有一部分心跳成分；**心率一變，aSKNA 就會跟著變**，比較不同心率的區間時要留意。若要去掉這部分干擾，請改用下面的 **S3 分解**，它是在波形形態上移除心電成分，不需要丟掉任何樣本。

Excel 會同時輸出 BPF 與 S3 兩組數字，方便互相對照。

### 🧬 S3 演算法

移植自 `CodeforTraining/` 裡的 MATLAB 參考實作（`AnalyzeExample.m`、`OSdecomp.m`、`optimal_shrinkage_color.m`、`stitchALL.m`、`createPseudoNoise.m`）。

**原理**：SKNA-I = 心電成分 + 交感神經活性 + 雜訊。把每個心跳以 R-peak 對齊、切成等長片段排成矩陣後，心電成分因為各次心跳形態高度相似而呈現**低秩**，交感神經活性則是隨機的、散布在所有奇異值上。於是可以用**最佳奇異值收縮（eOptShrink）**把低秩的心電成分估出來，從原訊號減掉。

流程：

```
原訊號 → 高通 1 Hz → R-peak 對齊切片 → 心跳矩陣 (p × n)
      → 最佳奇異值收縮 → 非局部中位數 (K=30)
      → 交叉淡入淡出接回時間軸 → 心電成分估計
      → 原訊號 − 心電成分 − 慢速漂移 → 不含心電干擾的 SKNA
```

**為什麼比 BPF 好**：BPF 是在頻率上切，但 QRS 的諧波本來就落在 SKNA 的頻帶裡，切不乾淨。S3 是在波形形態上切，跟頻率無關，所以能保留完整頻譜的 SNA，也能清理 BPF 完全處理不了的低頻帶。

用 `AMI 02.edf`（小鼠，HR 約 390–465 bpm，12.6 分鐘）實測的心跳殘留比（QRS 窗內／窗外的帶通振幅比；1.0 代表完全看不出心跳痕跡）：

| 頻帶 | 原始 | S3 後 | 假影移除 |
|---|---|---|---|
| 500–1500 Hz | 2.58 | 1.45 | 71% |
| 500–1000 Hz | 2.80 | 1.49 | 73% |
| 300–500 Hz | 2.85 | 1.33 | 82% |
| **50–300 Hz** | 2.33 | **1.14** | **89%** |

50–300 Hz 這一段是 BPF 完全束手無策的（心電主能量就在那裡），S3 卻能清到接近 1.0。

**效能**：12.6 分鐘、10 kHz 的檔案約 8–16 秒，峰值記憶體約 1.3 GB。分解在背景執行緒進行，有進度條可取消。結果會快取起來，之後所有區間分析直接取用；換檔案或改動來源通道／S3 參數時會自動失效並提示重跑。

**注意**：S3 需要形態穩定的心跳才能建立低秩模型。訊號品質差的段落（電極接觸不良、動物掙扎）分解會失敗或產生不合理的數值——`AMI 02` 錄製開頭 0–30 秒就是這種情況，品質警示欄會標出來。

### ⚠️ 訊號品質檢查（飽和 / 死訊號）

開檔時會自動檢查每個通道，有兩種「這段沒有可用訊號」的情況：

- **放大器飽和** — 訊號被推到滿格，波形削平成一條直線
- **死訊號** — 在 5 ms 窗內完全沒有變化。原始通道飽和時，由它衍生的濾波通道不會停在滿格，而是停在某個定值（例如高通後停在 0），光看有沒有貼齊極限抓不到

兩者都代表那段資料不含訊號內容：算出來的 aSKNA 沒有物理意義，S3 也無法分解（心跳形態被削掉了，對不齊）。

程式的處理：

| 位置 | 行為 |
|---|---|
| 開檔 | 有通道缺陷 ≥5% 時跳出警告，列出各通道比例（長檔案採等間隔抽樣估計，誤差 <0.1 個百分點） |
| 自動選通道 | 缺陷每 1% 扣分，會主動避開壞掉的通道 |
| SKNA 設定 | 下拉選單標示 `⚠ 飽和 17%`，選到時提示文字轉黃警告 |
| 區間分析 | 每列有「無效%」欄與品質警示 |
| S3 分解 | 缺陷 >50% 直接擋下並說明原因；≥5% 完成後跳警告 |
| Excel | 「無效訊號 (%)」欄與品質警示欄 |

實例：`HFD2-4.edf` 的 CH1 `tungsten raw` 有 17.3% 飽和（集中在第 2–6 分鐘），程式會自動改選 CH4 `Mice SKNA`。若你仍想用 CH1，可以只分析 480 秒之後的乾淨區段——實測那樣做 S3 效果很好（50–300 Hz 殘留比 11.12 → 1.20）。

### R-peak 來源

心率統計與 S3 對齊都需要知道 R-peak 在哪裡。預設使用 **SKNA 專用的偵測演算法**，它會先用自相關估出心動週期，再據此設定門檻與不應期，因此能自動適應人類與小鼠等差異極大的心率。

主畫面「偵測 R-peaks (P)」用的是另一套為人類心率設計的演算法，在高心率下峰值位置會抖動得很厲害。**只有在你已經人工校正過畫面上的峰值、想沿用時**，才在設定裡把來源改成「沿用畫面上的 R-peak 標記」。

### 匯出的指標

| 指標 | 定義 |
|------|------|
| **aSKNA** | 區間內 \|rSNA\| 的平均值（µV），文獻最常用的交感活性指標 |
| **iSKNA** | aSKNA × 區間長度（µV·s），區間之間可直接比較 |
| **RMS** | rSNA 的均方根 |
| **Peak** | 區間內 \|rSNA\| 的最大值 |
| **SD** | rSNA 的標準差 |
| **品質警示** | 心率超出生理範圍、RR 不穩、波峰因數過大時標示（僅提示，不會自動剔除資料） |

所有數值欄位（畫面表格與 Excel）都標註單位：振幅類為 **µV**、積分類為 **µV·s**、時間 **s**、心率 **bpm**、比例 **%**。若來源通道的單位無法辨識，就不換算並沿用原單位，欄位標題也會跟著顯示那個單位。

Excel 每一列會**並列兩組數字**，方便直接對照：

- `BPF aSKNA` 等 — 傳統帶通，區間內全部樣本都計入（含 QRS）
- `S3 aSKNA` 等 — S3 分解掉心電成分後再套同一個帶通

兩組數字的差距就是心跳成分的殘留量：BPF 含有心跳洩漏，S3 已把它扣掉，所以在高心率的資料上 BPF 會系統性偏高。把同一份資料的 BPF 與 S3 併排看，可以直接判斷該段結論會不會被心率變化帶偏。

單位會依通道原始單位自動換算成 **µV**（mV→×1000）。無法辨識的單位不做換算，直接沿用原單位並在介面標示。

Excel 有兩個分頁：

- **SKNA Intervals** — 每個區間一列
- **Settings** — 完整記錄檔案資訊與所有處理參數（含 S3 的執行範圍、心跳數、有效秩、K 值、執行時間），確保結果可重現、可被檢視

### 兩種匯出方式

「SKNA 區間分析」視窗右下角有兩顆按鈕：

| 按鈕 | 行為 |
|---|---|
| **匯出並開啟 Excel** | **不問存檔位置**，直接把結果寫成暫存檔並用 Excel 打開。先看數字、確認沒問題，再在 Excel 裡「另存新檔」決定要不要留、留在哪 |

## ❓ 常見問題

**Q：SKNA 波形看起來全是心跳的尖峰？**
A：這正是論文描述的頻譜洩漏，BPF 模式在頻率上切不掉它。請改用 **S3 分解**，它是在波形形態上移除心電成分，並對照 Excel 裡 BPF 與 S3 兩組數字的差距。

**Q：頻帶旁邊出現 ⚠？**
A：高截止超過該通道的 Nyquist 了。請改用較低的頻帶預設，或改選取樣率更高的通道。

**Q：開檔要等一下？**
A：`.edf` 約 0.2–0.3 秒，`.acq` 約 1.5–1.7 秒（BIOPAC 原生格式需要解壓縮，這段無法避免）。讀取期間起始畫面會顯示「⏳ 正在讀取…」並暫時停用按鈕，不是當掉。開檔完成前工具列不會出現。

**Q：按「選擇檔案」後要等一兩秒才能動？**
A：那是 macOS 原生選檔視窗在解析側邊欄位置造成的，尤其側邊欄有 Google Drive、iCloud Drive 這類網路位置時。程式本身沒有在做事。若影響到使用，可以在 Finder 的側邊欄把用不到的網路位置移除。

**Q：某個通道在畫面上只剩一條直線？**
A：那個通道在那段時間放大器飽和了（訊號被推到滿格削平）。看側邊欄或「SKNA 設定」的通道下拉選單會標出飽和比例。請改用其他通道，或只分析沒有飽和的時間範圍。

**Q：波形貼在圖框邊緣看不清楚？**
A：V4 已改用自訂的縱軸自動縮放，會保留 8% 邊距；訊號幾乎是常數時也會給可讀的範圍，不會再縮到 1e-4 mV 那種沒有意義的窄帶。按各軌的「自動」按鈕可隨時回到自動縮放。

**Q：S3 分解失敗，說 R-peak 不足？**
A：S3 是靠對齊心跳來分解的，至少需要 10 個心跳。請確認「SKNA 設定」裡的 **ECG 參考通道**選的是 QRS 清楚的那一條；如果只跑一小段範圍，也請確保範圍夠長。

**Q：S3 跑完，數字反而比原始還大？**
A：多半是那段訊號品質太差，心跳形態不穩定，低秩模型建不起來。先看「疊心電成分」疊出來的紅線有沒有貼合實際 QRS；若完全對不上，那段就不適合用 S3，也不建議拿來做結論。

**Q：「疊心電成分」點了沒反應？**
A：這在 V4 早期版本是個 bug（紅線被畫在畫面外），已修正。現在紅線會自動平移到原始訊號的準位，和藍線疊在一起。判讀方式：紅線的 QRS 若貼合藍線的 QRS，代表分解可信；若完全對不上，那段就不適合用 S3。實測 `AMI 02` 在 QRS 窗內的重建相關性 r = 0.99。

**Q：選了 S3，但畫面看起來完全沒變？**
A：先確認軌道 2 的標籤。如果還是「CH1: tungsten raw」這種通道名稱，代表 SKNA 顯示根本沒開——按 **K** 或工具列「SKNA」。如果標籤是 `SKNA [BPF] ... ⚠ 尚未執行 S3 分解`，代表演算法選了 S3 但還沒跑分解，按右側欄位的「S3 分解（整檔）」即可。分解完成後程式會自動切到 SKNA 顯示。

**Q：改了設定之後 S3 欄位變空白？**
A：換了來源通道或 S3 參數，之前的分解結果就不適用了，程式會自動作廢並提示。重新按一次「S3 分解」，再回區間視窗按「重新計算全部」。

**Q：某個通道的波形時間軸看起來不對？**
A：V4 已修正各通道不同取樣率的處理。若仍有問題，請確認側邊欄「取樣率」欄位顯示的是否為多個數值（混合取樣率）。

**Q：匯出 Excel 失敗？**
A：檔案可能正在 Excel 中開啟，關閉後再試。用「匯出並開啟 Excel」時會自動加序號避開這個問題。

**Q：按了「匯出並開啟 Excel」，Excel 沒跳出來？**
A：狀態列會顯示檔案的實際路徑，可以自己去開。若系統沒有把 .xlsx 關聯到任何程式，也會另外跳訊息框告知路徑。

**Q：macOS 雙擊 install.command 沒反應？**
A：按住 Control 鍵再點擊，選「開啟」。

**Q：pip 套件安裝失敗？**
A：macOS：`python3 -m pip install -r requirements.txt`；Windows：`py -m pip install -r requirements.txt`
